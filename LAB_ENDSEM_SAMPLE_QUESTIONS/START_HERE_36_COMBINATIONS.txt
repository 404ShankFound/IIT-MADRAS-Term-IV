36 CLIENT/SERVER PRACTICE COMBINATIONS
======================================
Every COMBO folder covers Labs 1, 2, 3, 5, 6, 7 and 8. Lab 4 is excluded.
Start with COMBO_01; it is closest to the supplied hospital example.
Each contains server.py, client.py, algos_used, PRACTICE.txt and requirements.txt.
Keep both terminals in the SAME example folder. Follow PRACTICE.txt.

HOW TO STUDY
1. Learn the shared menu, JSON socket functions and handle_request structure.
2. Read algos_used before each example; locate those helpers in server.py.
3. Trace upload/get first, then search, then classical/homomorphic operations.
4. Compare nearby folders; the algorithm helpers change while the flow stays similar.
5. All examples are standalone and can be copied individually for practice.

MANUAL ALIGNMENT / CORRECTIONS
Sources: supplied Labs 1-4 manual (Lab 1 pp.12-13, Lab 2 pp.20-21,
Lab 3 pp.30-31; PDF page numbers), Labs 5-6 manual (pp.2-3, 7-8),
Labs 7-8 manual (pp.7-15). Lab 4 content is deliberately omitted.
The Lab 7 sample labelled Paillier does not implement Paillier correctly;
these examples use phe. ElGamal multiplication does not implement greater-than.
The Lab 8 sample compares randomized ciphertexts for equality, which cannot
reliably match words. SSE here uses deterministic keyed tokens. RSA/Paillier
examples use encrypted indexes with explicitly labelled private-key owner
scanning, not a claim of full trapdoor-based searchable encryption.
The Lab 6 DH suggestion is treated as Lab 3 agreement, not a signature.
Signatures use RSA, ElGamal or Schnorr. The hospital algos_used calls RSA PSS,
but its code uses PKCS#1 v1.5; new labels match their actual code.
Not every optional manual exercise is represented (e.g. Snort/GnuPG and
cryptanalysis); this collection targets simple combinations of the seven labs.

VALIDATION
All 36 examples passed encryption/decryption, signatures, tamper rejection,
ten-document search, Unicode document content, duplicate/invalid requests,
role restrictions, classical cipher checks and homomorphic calculations.
All 36 passed socket login/request tests; COMBO_01 and COMBO_36 also passed
full interactive client/server runs. Re-run from the project root with:
python tests/test_generated_combinations.py
Use a Python environment with pycryptodome and phe installed.
