FASTEST METHOD
--------------
1. Search the question for its strongest keyword or special requirement.
2. Match it using the list below.
3. Open the corresponding Q-numbered Python file.
4. Read the short requirements at the top before copying the solution.

IMPORTANT DECISION RULES
------------------------
- Three roles + upload + verify + audit normally means Q01-Q07 or Q12.
- Hybrid means a public-key method protects/creates an AES session key.
- If the question only asks algorithms/timing/graph, use Q13-Q20.
- If it asks multipart hashing sockets, use Q11, not Q18.
- If it asks signature sockets, use Q18, not Q11.
- If the named encryption algorithm differs in a large role question, use the
  separate 168-permutation pack and select the matching ROLE algorithm file.
