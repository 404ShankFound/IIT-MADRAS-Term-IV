LARGE ROLE-BASED EXAM QUESTION
  Open EASY_EXAM_TEMPLATE.py from the main folder.
  Change only EDIT BOX 1 (logins/printed role names) and EDIT BOX 2
  (DES/AES name and key). The internal variable/function names stay unchanged.

HOSPITAL + AES EXAMPLE
  Do NOT paste AES functions from another file. In EASY_EXAM_TEMPLATE.py set:

      CIPHER_NAME = "AES"
      CIPHER_KEY = b"0123456789ABCDEF"

  The existing encrypt_data() and decrypt_data() then use AES automatically.

WHAT MAY NEED EDITING IN A SMALL ALGORITHM FILE
  If the question gives fixed plaintext/key values, replace the input() lines
  in the final main block with those values. Otherwise change nothing.
  IV or nonce is changed only in files that ask for it.

Do not combine two files unless the question explicitly asks for two
algorithms. Every encryption file deliberately uses the same names:

    encrypt_data(data, key, ...)
    decrypt_data(encrypted_data, key, ...)

Every signature file uses:

    generate_keys()
    sign_data(data, private_key)
    verify_signature(data, signature, public_key)

Every hashing file uses:

    hash_data(data, algorithm)
    verify_hash(data, expected_hash, algorithm)

PyCryptodome files require: pip install pycryptodome
