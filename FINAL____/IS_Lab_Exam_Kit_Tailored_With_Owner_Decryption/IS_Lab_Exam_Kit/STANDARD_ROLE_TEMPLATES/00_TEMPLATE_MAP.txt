STANDARD ROLE-BASED EXAM TEMPLATES
==================================

WHAT "HYBRID" MEANS
--------------------
A hybrid system uses two kinds of cryptography together:

    RSA / ECC / Diffie-Hellman  -> protects or creates the small AES key
    AES                         -> encrypts the actual record or file

This is done because AES is fast for data, while public-key algorithms make
key sharing safer. You do not combine any functions yourself; open the ready
RSA_HYBRID, ECC_HYBRID or DIFFIE_HELLMAN_AES file.

ZERO-THINKING METHOD
--------------------
1. Open READY_VARIANTS.
2. Pick the filename containing the algorithm in the question.
3. Copy the complete file.
4. Edit only EDIT BOX 1 when the story uses different role names/logins.
5. Edit plaintext/key values only when the question gives exact values.

Do not paste AES/DES/Hill/RSA functions from another file. Every READY_VARIANT
is already complete and includes encryption, decryption, hashing, signing,
verification, roles, keyboard/file input, timestamps and file storage.

ONLY COMMON STORY CHANGE
------------------------
For a hospital question, change only the displayed names in EDIT BOX 1:

    ROLE_NAMES = {
        "uploader": "Patient",
        "reviewer": "Doctor",
        "auditor": "Administrator",
    }

For a university question use Student, Faculty and HoD. For a company question
use Employee, Manager and Administrator. Internal words such as uploader,
reviewer, auditor, record and username never need changing.


IMPORTANT NOTES
---------------
1. Signature and hashing algorithms do not themselves provide encryption.
   Their templates still include easy AES encrypt_data() and decrypt_data()
   functions so the complete role-based answer has both operations.

2. Playfair changes J to I and may insert X. Hill/transposition may add a final
   X as padding. This is normal.

3. Small RSA, ElGamal and Rabin values are educational and intentionally easy.
   Use the hybrid template when the question explicitly asks for realistic
   file/message encryption.

4. PyCryptodome must be installed before the offline exam:

       pip install pycryptodome
